# SAS Programming Portfolio

## Overview

This repository showcases a collection of SAS programming projects demonstrating practical applications of data management, data transformation, statistical analysis, ETL workflows, exploratory data analysis (EDA), SQL-based data manipulation, and predictive modeling.

The projects were developed using SAS Studio and cover core concepts commonly applied in healthcare analytics, clinical data management, biostatistics, and business intelligence workflows.

---

## Project Objectives

The primary objective of these projects was to gain hands-on experience with:

* SAS Studio environment and navigation
* Data extraction, transformation, and loading (ETL)
* Exploratory Data Analysis (EDA)
* Data cleaning and preprocessing
* Missing data identification and handling
* Data standardization and transformation
* SQL-based data manipulation using PROC SQL
* Dataset merging and joining techniques
* Linear Regression modeling
* Binary Logistic Regression modeling
* Statistical reporting and summary generation
